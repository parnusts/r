# r

หน้าส่งต่อลิงก์สั้นของบัตรเชิญงาน STS Event

`https://parnusts.github.io/r/?<token>` จะพาไปหน้าบัตรเชิญของผู้รับคนนั้น
หน้านี้ไม่เก็บข้อมูลใด ๆ และไม่มีข้อมูลของผู้รับอยู่ใน repo นี้

**ระหว่างที่บัตรเชิญยังใช้งาน ห้ามลบ ห้ามเปลี่ยนชื่อ repo และห้ามปิด GitHub Pages** — ลิงก์และ QR ที่แจกไปแล้วจะเปิดไม่ได้

`index.html` สร้างด้วยสคริปต์ของโปรเจ็กต์หลัก อย่าแก้ด้วยมือ
